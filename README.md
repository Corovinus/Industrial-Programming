🖥️ Лабораторные работы по курсу программирования
Этот репозиторий содержит решения лабораторных работ, выполненные в рамках курса программирования. Работы написаны на Java и охватывают темы работы с массивами, строками, потоками, коллекциями и базами данных.

📋 Список лабораторных работ

⚡ Лабораторная работа 1: Действительные числа
Описание:
Консольное приложение для вычисления приближённой суммы ряда Тейлора.
Функционал:
Вычисление значения ряда до момента, пока очередное слагаемое по модулю не станет меньше ε.
Ввод значений x и k с клавиатуры.
Сравнение результата с использованием стандартных функций.
Вывод результата с точностью до трёх знаков после запятой.

🧮 Лабораторная работа 2: Работа с двумерными массивами
Описание:
Программа для выполнения различных операций с матрицами.
Функционал:
Замена строк с наибольшим и наименьшим элементами.
Нахождение строк с нулевым элементом на главной диагонали.
Поиск чисел, встречающихся ровно дважды.
Сортировка столбцов по неубыванию их первых элементов.

✍️ Лабораторная работа 3: Работа со строками
Описание:
Программа для обработки текста с заменой символов.
Функционал:
Замена k-й буквы каждого слова на заданный символ.
Игнорирование замены, если длина слова меньше k.

📚 Лабораторная работа 4: Внутренние классы и коллекции
Описание:
Класс "Зачетная книжка" с внутренним классом для хранения информации о сессиях, зачётах и экзаменах.
Функционал:
Чтение данных о студентах из файла input.txt.
Сохранение информации об отличниках (оценки ≥ 9) в файл output.txt.

📂 Лабораторная работа 5: Работа с файлами
Описание:
Программа для чтения, обработки и записи текста в файлы.
Функционал:
Чтение текста из входного файла.
Обработка текста (конвертация) и запись результата в выходной файл.

🗄️ Лабораторная работа 6: Работа с MySQL
Описание:
Создание, удаление и управление элементами таблицы базы данных MySQL.
Функционал:
Работа с таблицами: добавление, удаление и связь элементов.

🔄 Лабораторная работа 7: Работа с потоками
Описание:
Программа с двумя потоками (Main и Sort) для сортировки массива.
Функционал:
Создание массива случайных чисел с заданной пользователем размерностью.
Запрос у пользователя порядка сортировки (возрастание или убывание).
Вывод массива до и после сортировки.
Использование Comparator для сортировки в потоке Sort.
